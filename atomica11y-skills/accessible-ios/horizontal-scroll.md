# iOS Horizontal scroll skills



## How to test a horizontal scroll 

Given that I am on a screen with a horizontal scroll

### 1. Keyboard only

- WHEN I use the arrow keys or ctrl + tab to move focus to a control

  - I SEE focus is visually indicated (strongly if high contrast enabled)

- THEN when I use the spacebar to activate the control
 
  - I SEE the action occurs


### 2. VoiceOver screenreader

- WHEN I use a screenreader AND I swipe to browse the content

  - I HEAR its purpose is clear (typically from a heading above)

  - I HEAR content item index is announced (ex: 3 of 5)

- THEN when I doubletap with a control in focus
 
  - I HEAR the action occurs


### 3. Device settings

- WHEN I use text resize I SEE text can resize up to 200% without losing information

# iOS Progress gauge skills



## How to test a progress gauge 

Given that I am on a screen with a progress gauge

### 1. Keyboard only

- WHEN I use the arrow key to browse to a gauge

  - I SEE the gauge comes into view


### 2. VoiceOver screenreader

- WHEN I use a screenreader AND I perform an action that initiates a gauge

  - I HEAR its purpose is clear and matches visible content

  - I HEAR it has no role

  - I HEAR the screenreader reads the gauge and announces any current dynamic value (ex: downloading receipt 12%)

- OR when I swipe to browse to the gauge
 
  - I HEAR the screenreader reads the gauge and any current dynamic value


### 3. Device settings

- WHEN I use text resize I SEE text content can resize up to 200% without losing information

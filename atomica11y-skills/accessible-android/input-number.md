# Android Number input field skills



## How to test a number input field 

Given that I am on a screen with a number input field

### 1. Keyboard only

- WHEN I use the ctrl + tab or arrow keys to move focus to the input

  - I SEE focus is visually indicated


### 2. Android screenreader

- WHEN I use a screenreader AND I swipe to focus on a text input

  - I HEAR its purpose is clear and matches visible label

  - I HEAR it identifies itself as text field

  - I HEAR its visible label and instructions are read with the input in focus

  - I HEAR if applicable, it expresses its state (required, dimmed, invalid)


### 3. Device settings

- WHEN I use text resize I SEE text can resize up to 200% without losing information

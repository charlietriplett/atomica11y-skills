# Design Decorative image / icon skills



## How to test a decorative image / icon design

A decorative image / icon must meet WCAG principles:

### 1. Perceivable

- All non-text content that is purely for decoration or which repeats existing on-screen text nearby should be ignored and skipped over by screenreaders 1.1.1 A

A decorative image / icon must work for people with disabilities:

### Blindness

- All non-text content that is purely for decoration or which repeats existing on-screen text nearby should be ignored and skipped over by screenreaders 1.1.1 A

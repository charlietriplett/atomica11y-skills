# Design Card box skills



## How to test a card box design

A card box must meet WCAG principles:

### 1. Perceivable

- Text can resize up to 200% with no loss of information - 1.4.4 AA
- Text has a 4.5:1 minimum contrast ratio 1.4.3 AA

### 2. Operable

- The click/tap target area for individual components is defined and is no smaller than 24x24px - 2.5.8 AA
- The click/tap target area for individual components is defined and is no smaller than 44x44px - 2.5.5 AAA
- The focus indication for individual components is defined and visible (in some way) 2.4.7 AA
- The focus indication for individual components is defined and has a 3:1 minimum contrast ratio against default and adjacent elements - 2.4.13 AAA
- The focus indication has a minimum area equal to the width of the element and 2px in height - 2.4.13 AAA

### 4. Robust

- Name and role of individual components is documented  4.1.2 A
- Meets criteria across platforms, devices and viewports 4.0.0 AA

A card box must work for people with disabilities:

### Low vision

- Text can resize up to 200% with no loss of information - 1.4.4 AA
- Text has a 4.5:1 minimum contrast ratio 1.4.3 AA

### Motor

- The click/tap target area for individual components is defined and is no smaller than 24x24px - 2.5.8 AA
- The click/tap target area for individual components is defined and is no smaller than 44x44px - 2.5.5 AAA
- The focus indication for individual components is defined and visible (in some way) 2.4.7 AA
- The focus indication for individual components is defined and has a 3:1 minimum contrast ratio against default and adjacent elements - 2.4.13 AAA
- The focus indication has a minimum area equal to the width of the element and 2px in height - 2.4.13 AAA

### Blindess

- Name and role of individual components is documented  4.1.2 A
- Meets criteria across platforms, devices and viewports 4.0.0 AA

# Design Alert notification skills



## How to test an alert notification design

An alert notification must meet WCAG principles:

### 1. Perceivable

- Text can resize up to 200% with no loss of information - 1.4.4 AA
- Text optically measuring >= ~18px has a 3:1 minimum contrast ratio - 1.4.3 AA
- Text optically measuring < ~18px has a 4.5:1 minimum contrast ratio - 1.4.3 AA
- Color is not used as the only means of conveying state (success/error/warning) - 1.4.1 A

### 2. Operable

- Alerts do not auto-dismiss 2.2.3 AAA

### 4. Robust

- Name and role is documented - 4.1.2 A
- Message is announced on appearance, does not take focus is documented - 4.1.3 A
- Meets criteria across platforms, devices and viewports 4.0.0 AA

An alert notification must work for people with disabilities:

### Low vision

- Text can resize up to 200% with no loss of information - 1.4.4 AA
- Text optically measuring >= ~18px has a 3:1 minimum contrast ratio - 1.4.3 AA
- Text optically measuring < ~18px has a 4.5:1 minimum contrast ratio - 1.4.3 AA
- Meets criteria across platforms, devices and viewports 4.0.0 AA

### Color perception

- Color is not used as the only means of conveying state (success/error/warning) - 1.4.1 A

### Blindness

- Name and role is documented - 4.1.2 A
- Message is announced on appearance, does not take focus is documented - 4.1.3 A
- Alerts do not auto-dismiss 2.2.3 AAA

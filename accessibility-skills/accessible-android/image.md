# Android Informative image skills



## How to test an informative image 

Given that I am on a screen with an informative image

### 1. Keyboard only

- WHEN I use the arrow key to browse to an image

  - I SEE the image comes into view


### 2. Android screenreader

- WHEN I use a screenreader AND I swipe to browse to an image

  - I HEAR the meaning of the image is clearly described

  - I HEAR it identifies its role as an image

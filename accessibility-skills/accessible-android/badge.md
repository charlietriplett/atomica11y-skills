# Android Badge skills



## How to test a badge 

Given that I am on a screen with a badge

### 1. Keyboard only

- WHEN I use the tab or arrow keys to move focus to a control with a badge

  - I SEE focus is visually indicated on the entire control NOT the badge


### 2. Android screenreader

- WHEN I use a screenreader AND I swipe to browse to a control with a badge

  - I HEAR the name of the control, then badge content (ex: home, 1 new notification)


### 3. Device settings

- WHEN I use text resize I SEE text content can resize up to 200% without losing information
